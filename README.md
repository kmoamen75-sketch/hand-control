# التحكم بالكاميرا (يد فقط)

شغّل: `pip install -r requirements.txt` ثم `python main.py` — للخروج اضغط **q**.

## المنيو
افتح **كفك الشمال** كامل → هتظهر أزرار على مفاصل الصوابع:
مفصل السبابة = CURSOR، الوسطى = DRAW، البنصر = FX، الخنصر = VOLUME، الرسغ = CLEAR.
ثبّت سبابة **اليمين** على الزرار حوالي نص ثانية عشان يتختار.

## الأوضاع
| الوضع | الاستخدام |
|---|---|
| CURSOR | حرّك السبابة اليمين = الماوس (بيمشي من مفصل السبابة فيبقى ثابت). قرّص الإبهام والسبابة = كليك، وكمّل قرص وحرّك = سحب (Drag) |
| DRAW | قرّص بيمينك وارسم. افتح/اقفل إبهام وسبابة الشمال لتغيير سُمك الفرشاة |
| FX | اعمل شكل بإيدك يتحول لجزيئات متوهجة (تحت) |
| VOLUME | يمينك فوق خط النص = صوت أعلى، تحته = أقل |

## أشكال FX
- كف مفتوح ← زحل 🪐
- قبضة ← مكعب
- صباعين (V) ← قلب ❤️
- 3 صوابع ← اسمك (غيّره من `YOUR_NAME` في main.py)
- صباع واحد ← HI
- إبهام + سبابة + خنصر ← I LOVE YOU
- إيدين بيعملوا قلب (السبابتين مع بعض والإبهامين مع بعض) ← قلب

## لو محتاج تظبط
- `ACTIVE_BOX` في main.py: المساحة من الكاميرا اللي بتغطي الشاشة كلها (صغّرها = حركة أقل للوصول للأطراف).
- `OneEuro2D(min_cutoff, beta)`: `min_cutoff` أقل = أنعم، `beta` أعلى = أسرع في الحركة السريعة.
- `PinchDetector(on, off)` في utils.py: حساسية القرص.
